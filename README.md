# dsh-knowspace

**Agent-Native Knowledge Management Plugin for DeepSeekHarness**

一个面向 [DeepSeekHarness](https://github.com/DeepSeekHarness) 生态的知识管理插件，旨在提供本地优先、Agent 原生集成、支持多设备同步的个人知识空间。

## Project Status

**Work in Progress (WIP) — MVP Under Development**

本项目目前处于早期开发阶段，正在进行核心功能的设计与实现。
实际开发暂时在私有仓库中进行，首个可用的 Alpha 版本完成后计划公开源码。

> This repository serves as the official project placeholder. The source code is currently under private development and is planned for public release with the first usable alpha version.

## Planned Features

- **Knowledge Workspace** — 多知识工作区管理，支持原生 Markdown 笔记及图片资源。
- **Agent Integration** — 与 DeepSeekHarness Agent Tools 集成，让 AI 能够搜索、读取、创建和修改知识。
- **Local-First** — 本地优先，支持离线阅读与编辑。
- **Multi-Device Sync** — 基于 WebDAV 的多设备双向同步，无需部署额外服务端。
- **Full-Text Search** — 本地全文索引，为 Agent 提供高效的知识检索能力。
- **Change Tracking** — 记录知识变更，支持差异查看和冲突保护。
- **Extensible Architecture** — 为未来的 RAG、语义检索、富媒体处理及垂直知识插件预留扩展能力。

## Design Philosophy

**Your Knowledge, Your Control.**

知识属于用户，Agent 只在需要时提供帮助。

- **Privacy First** — 用户控制知识访问权限与 AI 介入程度。
- **Open & Portable** — 本地知识使用开放文件格式，避免数据锁定。
- **Agent-Native** — 将知识管理能力直接融入 Agent 工作流。
- **Reliable by Design** — 优先保证数据完整性、同步可靠性与可恢复性。
- **Minimal & Extensible** — 保持核心轻量，通过插件扩展专业能力。
